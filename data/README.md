# Dataset

Download from Kaggle:
https://www.kaggle.com/datasets/clmentbisaillon/fake-and-real-news-dataset

Place these two files here:
- `Fake.csv`
- `True.csv`

Both files have columns: `title`, `text`, `subject`, `date`.

If you don't have them yet, run `python ../src/generate_sample_data.py` from
the `src/` folder to generate small placeholder versions so you can test the
pipeline immediately.
